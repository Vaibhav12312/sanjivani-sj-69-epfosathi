# EPFOSathi – Employee Provident Fund Assistance

## 1. Product
EPFOSathi is an employee-focused information and assistance project designed to help users understand India's Employees' Provident Fund (EPF) system.

It aims to make EPF-related information, basic guidance, and common questions easier to understand.

## 2. Target Users
- Private-sector employees
- EPF account holders
- New employees who want to understand PF
- Employees who need basic information about UAN, PF contributions, withdrawals and claims

## 3. Problem Statement
Many employees face difficulties understanding EPF rules, PF contributions, UAN-related processes, withdrawals and claim procedures.

Information can be confusing, and employees may not know where to find reliable guidance.

EPFOSathi aims to provide simple, structured and user-friendly EPF information.

## 4. Data Sources
The project will refer to official and reliable information sources:

- EPFO official website: https://www.epfindia.gov.in/
- EPFO Member Portal: https://unifiedportal-mem.epfindia.gov.in/
- Official EPFO circulars, notifications and FAQs

**Important:** EPFOSathi is an assistance and information project. It does not independently access private employee PF records.

## 5. Project Objective
To make EPF-related information easier to understand through simple Python programs and interactive features.
